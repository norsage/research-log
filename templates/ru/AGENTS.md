# ИМЯ-ПРОЕКТА

Этот файл — указатель. Правила описаны в документах, на которые он ссылается.
Не добавляй правила сюда: файл читают целиком перед каждой задачей, и он
должен оставаться коротким.

## Перед любой задачей

1. Прочитай [`docs/conventions.md`](docs/conventions.md): куда класть новый
   документ и что делать в каждой ситуации. Файл поставляется скиллом,
   править его не нужно.
2. Прочитай [`docs/conventions-local.md`](docs/conventions-local.md): правила
   этого проекта — стек, окружение, структура кода, инструменты, тесты.
3. Прочитай [`docs/vision.md`](docs/vision.md): цель проекта и что он
   сознательно не делает.

## Где что искать

| Что нужно | Где смотреть |
|---|---|
| цель проекта | [`docs/vision.md`](docs/vision.md) |
| куда класть документ и когда он меняет тип | [`docs/conventions.md`](docs/conventions.md) |
| стек, окружение, структура кода, внешние инструменты, тесты | [`docs/conventions-local.md`](docs/conventions-local.md) |
| что проверяется сейчас | [`docs/hypotheses/_index.md`](docs/hypotheses/_index.md) |
| что уже установлено | [`docs/findings/_index.md`](docs/findings/_index.md) |
| что зафиксировано и почему | [`docs/decisions/_index.md`](docs/decisions/_index.md) |
| что запускали и на каких данных | `docs/experiments/` |
| как что-то поставить, пересобрать, запустить | [`docs/protocols/_index.md`](docs/protocols/_index.md) |
| над чем идёт работа | трекер задач, вне этого репозитория |

## Куда что записывать

Числа, которые понадобятся для сравнения, записывает `record_run.py` в
эксперимент. Утверждения, которые остаются верными после прогона, — в находку.
Остальное — в трекер задач.

Перед коммитом запускай `check.py`.
