# Vision

The project's current goal. When it changes, rewrite this file. If the
question narrows after the first numbers exist, also record that as a
decision, with a date: it shows the question was changed with the results
already known. The results themselves do not go here.

## The question

One paragraph. What this project is trying to find out, in language someone
outside it can follow. The applied purpose belongs here too, if there is one.

## Directions

The lines along which the project looks for an answer. Empty at the start is
normal: directions appear as the work goes, when several hypotheses turn out
to be about the same thing. Each gets a subheading, with what it tests and
where it stands underneath. A direction that is set aside stays, with a line
on why, so that taking it up later is a conscious choice.
